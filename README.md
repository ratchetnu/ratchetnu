I like owning the whole path from an idea to a working system.

## How I approach AI

I don't treat model output as automatically correct.

I build checks around AI so the system can verify results, limit what the model can access, handle failures and stop unsafe changes before they reach users.

That includes:

- retrieval and RAG
- evaluation
- guardrails
- least-privilege access
- deterministic testing
- CI gates
- failure handling
